Documentación del Servicio

1. ¿Qué es RukaTV?

RukaTV es la aplicación cliente oficial para conectarse al servidor Rukaserver. Permite acceder a Canales de TV en vivo, Películas y Series directamente desde el servidor en tiempo real.

2. Protocolo de Conexión

Tipo: API REST compatible con Xtream Codes.
Formatos de stream: HLS (.m3u8), MPEG-TS (.ts), Progressive MP4.
Autenticación: Usuario y contraseña emitidos por el administrador del servidor.

3. Requisitos del Sistema

Android: 5.0 (Lollipop) o superior.
Dispositivos: Teléfonos, tablets, Android TV y Smart TV con Android.
Conexión: Wi-Fi o datos móviles de al menos 4 Mbps para HD y 20 Mbps para 4K.

4. Auto-Actualización (OTA)

La aplicación verifica automáticamente si existe una versión más reciente en el servidor al iniciar sesión. Si hay una actualización disponible, mostrará un aviso para descargar e instalar directamente.

5. Soporte

Para soporte técnico o acceso al servidor, contacta al administrador de tu cuenta en Rukaserver.
